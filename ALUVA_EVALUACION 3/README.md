# ALUVA — Sitio Web Final

Proyecto final de la asignatura **Diseño Web**.

## Descripción

Sitio web informativo y comercial para **ALUVA**, emprendimiento dedicado a ropa de trabajo, vestuario corporativo y elementos de protección personal (EPP). El proyecto fue desarrollado progresivamente utilizando HTML, CSS, Bootstrap y JavaScript.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 4
- JavaScript
- DOM y eventos

## Funcionalidades

- Diseño responsivo para computador, tablet y teléfono.
- Navegación por secciones.
- Catálogo de productos con filtro por categorías mediante JavaScript.
- Modo de alto contraste activado mediante un evento `click`.
- Formulario de contacto con validación usando eventos `blur` y `submit`.
- Estilos personalizados para mantener la identidad visual de ALUVA.

## Estructura

- `index.html`: estructura principal del sitio.
- `style.css`: estilos personalizados.
- `script.js`: interactividad y validaciones JavaScript.
- `img/`: imágenes del proyecto.
- `vendor/`: archivos locales de Bootstrap y dependencias.
